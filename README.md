# 펫초이스 — 새 독립 홈페이지

기존 `pet-nutrition` 저장소와 별도로 운영하는 강아지·고양이 종합 쇼핑 정보 홈페이지입니다.

## 새 GitHub 저장소 만들기
1. GitHub에서 New repository를 선택합니다.
2. Repository name에 `pet-shopping`을 입력합니다.
3. Public을 선택하고 Create repository를 누릅니다.
4. 이 폴더의 `index.html`을 새 저장소 최상위에 업로드합니다.
5. Commit changes를 누릅니다.
6. Settings → Pages → Deploy from a branch → `main` → `/(root)`를 선택해 저장합니다.

예상 주소: https://jsin42340-afk.github.io/pet-shopping/

## 현재 기능
- 강아지·고양이 통합 상품 카테고리
- 카테고리 및 대상 동물 필터
- 상품군 검색
- 브랜드 디렉터리
- 상품별 가격·성분 비교 기준

## 중요
현재 페이지는 카테고리/브랜드 탐색용 초기 버전입니다. 개별 SKU의 실제 가격·재고·리뷰·성분이 자동 연동되지는 않습니다. 상품 상세 DB를 추가할 때 공식 제조사·판매처 자료를 확인하고 확인일, 용량, 가격 단위를 기록하세요.
